# ПР-помощник — преждевременные роды и ПРПО

Веб-приложение для врача акушера-гинеколога: ведение пациентки с **преждевременными родами (ПР)** и
**преждевременным разрывом плодных оболочек (ПРПО)** при недоношенной беременности по клиническим
рекомендациям РОАГ «Преждевременные роды» (**2024**, ID 331; МКБ-10 O60, O47.0, O42). Учтены смежные КР:
«Аномалии объёма амниотической жидкости» (2024), «Многоплодная беременность» (2024),
«Задержка роста плода» (2025), «Тазовое предлежание плода» (2024).

## Возможности

- **Тактика** — выбор ситуации (профилактика / угрожающие / начавшиеся / активные ПР / ПРПО / индуцированные ПР),
  срок по УЗИ 11–13+6 нед, ПМ или вручную, ключевые данные. Приложение подбирает рекомендации КР с УУР/УДД
  по сроку и данным: что **показано**, что **рассмотреть**, что **не рекомендовано** и что **противопоказано**
  (токолиз, профилактика РДС с учётом прошлых курсов, магния сульфат, антибиотики при ПРПО, СГВ, маршрутизация,
  профилактика ПР, способ родоразрешения, новорождённый). Подсказывает, если данные не соответствуют выбранной ситуации.
- **Чек-лист** с отметкой времени и примечаниями; пункты подстраиваются под ситуацию и срок, введённые препараты
  отмечаются автоматически.
- **Препараты и таймеры**: схемы и дозы по КР, журнал введений; следующая доза ГКС, 24 ч и контроль токсичности
  магния каждые 4 ч, график АД на фоне нифедипина, 48 ч атозибана/индометацина, ампициллин каждые 6 ч, 10 дней
  антибиотиков при ПРПО, предупреждения (≥ 3 токолитика, лихорадка, лейкоцитоз после ГКС).
- **Наблюдение**: АД, пульс, ЧДД, t, ЧСС плода, рефлексы, диурез; лейкоциты и СРБ.
- **Роды**: способ, анестезия, пережатие пуповины, пакет/лучистое тепло, новорождённый.
- **Конструктор заключений** (вкладка в карте пациентки и **отдельная страница** с главного экрана):
  диагноз и коды МКБ-10 формируются автоматически, план — из рекомендаций (пункты можно отключать),
  текст редактируется, копируется, печатается и выгружается в **Word**. Шаблоны:
  осмотр и заключение при поступлении; протокол врачебной комиссии на препарат вне инструкции (#нифедипин, #ГКС,
  #антибиотики, #индометацин); ИДС пациентки; консилиум о тактике и способе родоразрешения; дневник при ПРПО;
  обоснование перевода в стационар 3-й группы; эпикриз с критериями качества.
- **Отчёт**: 7 критериев качества КР (авто + ручная коррекция), хронология, выгрузка случая в Word и JSON.
- **Справочник**: алгоритм (Прил. Б), классификации, диагностика, тесты, токолиз, ГКС, магний, антибиотики,
  ПРПО, профилактика, родоразрешение, многоплодие, сроки при ЗРП, маловодие, дозы.
- Работает офлайн (PWA), данные только на устройстве (localStorage), тёмная тема, телефон и планшет.

## Запуск

```bash
npm install
npm run dev          # разработка
npm test             # тесты правил, конструктора и выгрузки .docx
npm run build        # сборка в dist/
npm run build:single # всё приложение в одном файле dist-single/index.html
```

GitHub Actions публикует сборку на GitHub Pages при пуше в основную ветку (Settings → Pages → Source: GitHub Actions).

## Структура

- `src/protocol/` — знания КР и чистая логика: `rules.ts` (рекомендации), `drugs.ts`, `checklist.ts`,
  `alerts.ts` (таймеры), `quality.ts`, `ga.ts` (срок), `data.ts`.
- `src/conclusions/` — диагноз/МКБ-10 и шаблоны заключений.
- `src/export/` — Word.
- `src/components/` — интерфейс.

> Средство поддержки решений и документирования; не заменяет клиническое решение врача и инструкции к препаратам.
> «#» — применение вне инструкции (off-label): заключение врачебной комиссии и письменное ИДС пациентки.
